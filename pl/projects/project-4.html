Formula 1 videogame

A Formula 1 inspired racing game made using Unreal Engine 5 for a college project. All of the environment with props were made by myself in Blender, then imported into UE5.

Key Technical Highlights and Features

  • Language & Design: Built using Unreal Engine 5 blueprints and code blocks.
  • Gameplay: Set lap times around a fully modelled 3D track inspired by a real life track; Tor Poznan.
  • Physics: Fully modelled driving physics with collisions and motions.
