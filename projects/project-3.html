Fuelstream

A Python application for visualising real Formula 1 telemtry pulled from an API. This includes lap times, driver head-to-heads and race position changes. It is a current work in progress and likely to change.

Key Technical Highlights

  • Language & UI: Built in Python with NiceGUI for a simple user interface.
  • Data: Integrated API calls for real and up-to-date Formula 1 telemetry.
  • Visualisation: Implemented pyplot to visualise the data from the API, all within NiceGUI for a easy user experience.
