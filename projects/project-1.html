A-Level Non-Examined Assessment (NEA)

A C# desktop application built during Sixth Form (2024) to analyse historical stock market data and model price trends using least squares linear regression and logarithmic calculations.

Key Technical Highlights

  • Language & UI: Built in C# with a Windows Forms aspect for the interface.
  • Data & File Handling: Integrated API calls alongside reading and writing text files.
  • Trend Modelling: Implemented least squares linear regression and logarithmic equations to analyse and predict price trends.
