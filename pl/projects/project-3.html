Fuelstream

Aplikacja stworzona z Pythonem w celu wizualizacji telemtrii z Formuły 1 używając danych z API. Obejmuje czasy okrążeń, porównanie kierowców i zmiany pozycji podczasz wyścigu. Obecny projekt.

Kluczowe Aspekty Techniczne

  • Język & Interfejs: Stworzone z Python oraz NiceGUI.
  • Dane: API które dostarcza prawdziwe dane telemetri F1.
  • Wizualizacja: Dodatek Pythona NiceGUI zintegrowany z PyPlot.
